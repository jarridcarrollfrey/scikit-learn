ALGORITHMS IMPLEMENTED
======================
1. Node2Vec          - Biased random walk embeddings
2. DeepWalk          - Unbiased random walk embeddings
3. WL Kernel         - Weisfeiler-Lehman graph kernel
4. RW Kernel         - Random walk graph kernel
5. Louvain           - Modularity-based community detection
6. Label Propagation - Fast community detection

✓ Inherit from BaseEstimator
✓ Proper fit/transform/predict methods
✓ Parameter validation with _parameter_constraints
✓ Fitted attributes end with underscore
✓ Support for random_state where applicable
✓ Comprehensive docstrings with examples
